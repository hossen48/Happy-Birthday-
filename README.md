# Adu — Birthday Website

A romantic interactive birthday website for Adu.

## Navigation
- Major pages use the **Before / Next** buttons only.
- Swipe is reserved for the **Love Archive photos**.
- Love Archive photos are `assets/photos/01.webp` through `10.webp`.
- Museum photos are `assets/photos/11.webp` through `30.webp`.

## Letter
The letter is sealed inside an animated envelope. Tap the envelope to open it; the exact letter appears after the flap opens.

## Compatibility Test
12 questions, one question per screen, based only on known details of Hossen + Adu's story: 2012, 24 January 2026, food trips, cooking, funny faces, hand-holding, ordinary days, Japan, their future plans, and choosing each other.

## Detective Adu
An interactive interrogation mystery with four questions, live evidence recovery, suspect selection, and a final case verdict.

## Birthday Cake
The candles have layered flame animation, blow-out/snuff timing, extinguished glow, and rising smoke before the wish confirmation.

## Music
`assets/bgm/birthday-bgm.mp3` is included.

## Photos
Photos are intentionally **not included** in this ZIP. Put your existing files in:

`assets/photos/01.webp` … `assets/photos/30.webp`

## Start locally
Open `index.html` in a browser. For the best result, use a simple local web server so all assets load correctly.
