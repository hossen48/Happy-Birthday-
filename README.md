# Adu — Birthday Website

## Important
The ZIP intentionally does **NOT** include the 30 photos. You already have them.

Place your existing files here:
`assets/photos/01.webp` through `assets/photos/30.webp`

The site uses:
- 01–10: Love Archive (Adu's individual photos + “things I love about you”)
- 11–30: Our Little Museum / shared-memory gallery

## Navigation
There are no Next/Previous chapter buttons.
- Swipe left/right anywhere to move between major pages.
- On desktop, use mouse wheel or arrow keys.
- Love Archive has its own independent horizontal swipe: each swipe changes BOTH the photo and the reason/topic.
- The Love Archive is deliberately one-card-at-a-time so the reason is visible with the photo.

## Visual style
Romantic night-garden aesthetic, floating glow, sparkles, animated heart elements, soft glass cards, cinematic page transitions, polaroid-like archive card, birthday cake interaction, animated terminal, quiz, timeline, and an animated hand-holding final scene.
