# Adu — Romantic Birthday Website

A spacious, click/swipe-based birthday experience with separate full-screen chapters.

## Included
- `index.html`
- `style.css`
- `script.js`
- `assets/bgm/birthday-bgm.mp3`
- `assets/photos/01.webp` … `30.webp`

## Design
- Each major experience gets its own full-screen page.
- Pages use a smooth slide/scale transition inspired by presentation morph-style movement, without copying the reference design.
- Love Archive is a one-photo-at-a-time swipe experience.
- **Single photos of Adu are restricted to Love Archive.**
- The museum/gallery uses the remaining shared photos.
- Birthday cake includes candle flames and a blow-the-candles interaction.
- Final page contains the hand-holding/promise animation.
- Music is the combined romantic instrumental BGM supplied for this project.
